## What changed

- **Maintainable boundaries:** the roughly 5,500-line CLI became thin dispatch plus cohesive package, execution, evidence and reporting modules. Operation-scoped immutable inputs reduce repeated work without sharing mutable subject processes.
- **Exact performance improvements:** the largest sparse matrix fixture fell from about 6.4 seconds to 1.28 seconds, with all six output digests unchanged and peak worker RSS about 196 to 140 MiB. Exact subset/matching and missing-cell semantics remain. This is not a claim of faster overall report rendering.
- **Storage reliability:** the old Node best-effort clone silently made full copies on this Mac; forced cloning reported ENOSYS. macOS publication now uses native APFS cloning, with independent inodes, exclusive publication and a space-checked full-copy fallback. A 974,869,504-byte clone took 4.59 ms and retained its exact digest. Integration budgets 16 GiB up front and checks a four-GiB reserve; the final run never fell below 20.20 GiB free.
- **Protected startup:** the generic runner no longer binds a short-lived host folder into every cell. Bounded captured public bytes arrive on stdin and become root-owned read-only files in private container tmpfs. Subject UIDs, working directory, private authority, network restrictions and capability limits are tested through the real route. No automatic grading retry was added.
- **Honest errors and gates:** startup, protocol, artifact and resource failures remain distinct. Bounded Docker diagnostics are retained. Negative protocol tests must demonstrate the intended error, not merely any failure. Whole-population starter checks reject infrastructure faults. External verification must actually complete the expected scenario population; output-file existence no longer passes its smoke test.
- **Read-only historical reports:** Phase 13 report/results/design use locked calibration; new grading is explicit `phase13 measure`. Phase 17 uses its unchanged retained preflight, not current credentials or Docker. Missing container receipts stay missing. Aggregate generation now includes the omitted Phase 17 report, for 141 reports.
- **Reproducibility and clarity:** exhaustive test tiers, required-runtime CI failures, intended-source recipient builds, version-separated historical/current artifacts and public architecture/testing documentation are maintained. Browser professional-v2 visible tests execute the starter, reference and legitimate alternative independently; historical v1 bytes were not rewritten.

The small 80-bind/80-container-local diagnostic passed both transports and did not establish Docker's internal root cause. The repair removes the transient host-mount dependency; it does not claim universal Docker reliability. A changing Docker Desktop row count is expected while disposable test containers run.
