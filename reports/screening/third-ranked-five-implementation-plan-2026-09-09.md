   execution sources. Leave both previous groups' exports and trial records intact.

   implementation modules with an empty entry point. Keep requirements, API schemas

## What changed

Every public workspace now has an empty service entry point, the API/domain
contracts and a concise checker interface. Both private service implementations
have complete module closures. Public solution modules and obsolete tests importing
them were removed; their original versions remain in the baseline snapshots.

All five have a complete private independent checker. It derives correctness from
raw inputs and effects, accepts alternative valid implementations, and uses the
same verdict schema as the public interface. Reason text is diagnostic, helpers
are available, and the repeated label-mapping and implementation tutorials are gone.

The source review rejected several local successor changes: maintenance would have
exposed computed safety verdicts, partial release would have lost initial resources,
rule index would have lost evaluated documents, and installation would have lost
raw availability inputs. Those facts are needed to judge correctness; retaining
them is not a solution tutorial.

The previous groups' authoring-policy improvements already apply. This work adds no
mandatory green starter tests, separate timed-human-solve gate, self-verifiability
disqualification or unrelated whole-batch iteration. The new controls enforce
documented behavior and retain clean witnesses, rather than relying on private
reason preferences. No crash or uncertain-commit mechanism was silently added to
snapshot recovery or installation.
