## Decisions

The minimal public starter supplies the required interface only. No algorithm, graph
traversal, caching policy, publication loop, reconciliation rule implementation, or
decoder is pre-implemented. Existing product requirements remain the basis for grading;
new complexity and shorter timeouts are not substitutes for substantive difficulty.

Checker classification remains a required professional deliverable: a release validator
for other implementations' observed executions. Explanatory strings do not affect reward.
The five tasks opt into the new interface through versioned package metadata; historical
snapshots retain their original grading policy.

Local engineering validation and final Klavis qualification are different milestones.
This implementation authorizes local checks, not new paid standard or adversarial trials.
The final six standard failures and two zero-reward cheat trials remain outstanding until
actually run on the final task. Model-powered rubric review is reported separately.

The current upstream guide requires four reviewer README sections to be written entirely
by a human. Generated technical notes can support that writing, but must not be presented
as human-authored prose. The eventual chosen submission needs that author input; it does not block exploratory
trials or require writing all five reviewer READMEs now.
