### Allocation completion reconciliation

The earlier allocation addendum called omission of a redundant terminal read a
leniency bug. The public contract already said that a disclosed leaf has no further
work. The maintained grader permits completion there, and this successor retains
that interpretation. A valid alternative and a regression now exercise it directly.
Trial 1 remains reward one; this is not a newly discovered model failure.

### Packaging and iteration fixes

- CAA's retained canary template had the template author's GUID rather than CAA's
  own GUID. The template explicitly instructs authors to substitute their unique
  GUID. Its task-local format runner now makes that substitution while retaining
  all file/comment checks. No check was removed. The existing CAA GUID is preserved.
- Renamed CAA's existing reviewer heading to `Relevant experience`, matching the
  current static schema without inventing new experience text.
- The static-check wrapper now refuses nonexistent or incomplete task paths before
  invoking scripts that can otherwise report success after inspecting no files.
  A regression verifies that no success summary is produced for a missing task.
- Removed the obsolete assertion in native export reproduction that local assurance
  must leave exploratory eligibility false. Reproduction still rejects an unsupported
  authorization, hardness or release claim. No extra human-timed-solve gate was added.
- Generator version records bind the knowledge and capacity additions to their new
  bytes while preserving both original selection ledgers.
