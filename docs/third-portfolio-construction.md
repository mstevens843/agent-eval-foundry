## Design and acceptance

| Package | Professional objective and interacting obligations | Independent evidence | Legitimate easy solutions remain allowed |
| --- | --- | --- | --- |
| snapshot-recovery-repair | Restore a selected database point, produce a portable backup, preserve relationships and allocation state | Fresh SQLite restores and separately folded source history | Full materialization instead of incremental restoration |
| verified-installation-repair | Install committed content with cache validation, ordered layer changes and metadata | Actual filesystem readback and independent layer semantics | Rebuild the complete tree |
| capacity-maintenance-repair | Finish host maintenance while preserving overlapping service availability and placement | Every authoritative state transition and completed work | Exhaustive planning within small documented bounds |
| route-policy-repair | Change scoped routing behavior without changing unrelated route decisions | Independently interpreted policy on a complete route population | Generate a new equivalent policy instead of a minimal patch |
| rule-index-repair | Compile efficient wildcard routing while preserving ordered-rule outputs | Host-owned bytecode work counter plus independent exhaustive semantics | Any equivalent bounded plan; no ban on standard algorithms |

Every package needs working starter smoke tests, a correct reference, a differently structured
correct implementation, narrow negative controls, no-work and forged-report controls,
actual isolation probes, deterministic scenarios, repeatability and recipient verification.
Author-side tests establish construction validity, not model difficulty. A 2–3 hour expert
repair target needs independent review; it is not established by an author estimate.

## Transfers and exclusions

Transferred engineering: complete outcome contracts; natural separation of meaningful
components; independent execution evidence; completion plus collateral preservation;
near-correct controls; reproducible scenarios and immutable receipts. No task gets payment
receipts, revocation or random crashes merely because the outbox used them.
The corrected foundry finding records six historical zero rewards but five ambiguity
adjudications and one unresolved result. It does not justify a universal model weakness.

The older five proposals were underspecified or unconstructed, not proven easy by solving
trials. These descendants explicitly expand their contracts. OCI-like layer semantics below
are a bounded, fictional package format, not a claim of full OCI compliance.

## Freeze protocol

Development scenarios and controls may evolve together, with failed checks retained.
After they pass, freeze generator hashes; add a new narrow control without changing selection.
Once exposed, that control is regression evidence, no longer held out.
No paid calls, shared trial mutation, automatic fairness approval or screening authorization.

## Corrections during construction

The first installation verifier incorrectly required the origin to remain available even
when a valid cached copy matched the exact committed bytes. The corrected contract and
independent truth calculation accept either verified source. The alternative implementation
now exercises origin-first/cache-fallback recovery; three additional cases and an origin-only
negative control cover this boundary. The earlier source and receipts remain preserved.

The compiler accepts legitimate all-negative populations and empty rule sets: positive work
means producing the correct executable plan, not inventing a matching document. Its starter
now also exercises ordering and capture-policy repair alongside bounded work. Maintenance
requires restoration as well as safe evacuation and upgrades. These are stated native
obligations, not extra hidden grading requirements.

Every package has an example-hardcoding control. Backup uses fresh SQLite databases,
installation reads real filesystem state, and all five inherit the same protected execution
and export boundary. Passing these controls is local assurance, not an official /cheat result.
