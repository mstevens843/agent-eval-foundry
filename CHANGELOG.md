# Changelog

## 0.2.0 — Developer onboarding

- Runnable latest-record template, task manifests and custom-source assembly without registry edits.
- Public `foundry` CLI with help, task listing, prerequisite checks and actionable diagnostics.
- Exported recipient README and a complete install/build/grade/export walkthrough.
- Frozen replay of an original incremental-build checker's premature-publication defect.
- One-trial configuration, planning and explicit subscription execution through the existing adapter.
- Automated onboarding verification, contribution instructions and MIT project license.

The `foundry` executable now opens the package/developer CLI. Historical research commands
remain available through `axis` / `pnpm axis`; `pnpm package:local` remains supported.
Use a source checkout or source release: the npm package remains private.

This version does not add tasks or trials to the published screening totals. Newly assembled
packages receive new identities because their bundled tooling changed. Historical exports
and their grading records retain their original identities.

Release status and verification procedure: [docs/releases.md](docs/releases.md).
